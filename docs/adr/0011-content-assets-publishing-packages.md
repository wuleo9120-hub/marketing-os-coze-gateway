# ADR 0011: Content Assets and Publishing Packages

## Status

Accepted.

## Context

Content generated by agents should become manageable assets instead of staying only inside task output. Publishing should produce platform-specific packages and jobs, with approval gates before live execution.

## Decision

Add content operations:

```text
apps/api/src/core/content-ops.mjs
```

Data:

- `content_assets`
- `publishing_jobs`

API:

```text
GET  /api/content/assets
POST /api/content/assets
POST /api/content/publishing-packages
```

Behavior:

- `content_creation` and `video_production` tasks create draft assets.
- `publishing_ops` tasks create platform packages and publishing jobs after approval.
- Packages are created for Douyin, Xiaohongshu, and Video Account when requested.

## Future Upgrade

- Add file/media assets.
- Add calendar scheduling.
- Add platform-specific validation.
- Add official API publishing connectors.
- Add per-platform performance metrics.
